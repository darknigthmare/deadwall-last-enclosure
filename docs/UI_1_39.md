# Clavier de l’établi — 1.39

## Défaut reproduit

L’établi technique ciblait le premier bouton de sa liste à l’ouverture, même lorsque ce bouton était désactivé. Approcher un groupe électrogène intact puis ouvrir **INTERVENTIONS** suffisait : « Réviser » était indisponible et ne pouvait recevoir le focus dans un navigateur.

Le même défaut apparaissait pendant un rafraîchissement : lorsqu’un infecté approchait d’un groupe endommagé avant le début de la réparation, « Réviser » devenait désactivé. L’ancien bouton focalisé était retiré et le contrôleur tentait de focaliser son remplaçant indisponible.

## Correction

`src/interventions-ui134.js` sélectionne la première action utilisable ou, si aucune n’est disponible, **FERMER · ÉCHAP**. Un bouton conservant son identité et sa disponibilité garde le focus. Le rafraîchissement ne crée aucune tentative, ne prélève rien et ne suspend pas le monde.

La disposition CSS, les contrôleurs d’armurerie et de barricades, les sauvegardes et les coûts restent ceux des systèmes existants. Les panneaux et boutons du HUD gardent leurs propriétaires et écouteurs.

## Preuves

`tests/ui139.test.cjs` charge le HTML et tous les scripts dans leur ordre de livraison. Sa fixture ajoute au DOM simulé la règle native refusant le focus sur un bouton désactivé ; elle ne simule pas le rendu CSS.

Les trois scénarios couvrent :

- le groupe intact sans action technique disponible, ouvert par le vrai lanceur du HUD ;
- le groupe endommagé dont l’action focalisée devient indisponible en présence d’un infecté ;
- le démarrage payé d’un mini-jeu et la conservation du focus sur Ajuster après une commande.

Avant correction : **2 échecs et 1 contrôle réussi**, dans `reports/1.39.0/ui139-before.log`. Après correction : **27/27 tests réussis**, sans ignorés, dans `reports/1.39.0/ui139-targeted.log`. Cette sélection conserve les contrôles HUD 1.35/1.36, la cascade CSS 1.37, le cycle modal de l’armurerie 1.37 et les interruptions d’établi 1.38.

Ces contrôles vérifient notamment l’identité des nœuds déplacés, les tiroirs exclusifs, les commandes tactiles simulées, la priorité du placement sur Échap, les modales, l’introduction, le menu, la mort, la nouvelle campagne et la reprise. Aucun nouveau défaut n’a été reproduit dans ces parcours existants ; ce constat n’est pas une certification générale de leur présentation.

La vérification globale `npm run check` appartient au contrôle final de la livraison. Aucun navigateur natif, CSS interactif, périphérique tactile, audio ou FPS GPU n’a été certifié ici.
