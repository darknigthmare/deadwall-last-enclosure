# Supports D-17 — cohérence visuelle 1.52

Quatre atlas originaux Image Gen remplacent les représentations géométriques de 28 supports existants. Les PNG natifs sont copiés sans retouche de pixels et les originaux restent conservés dans `/workspace/generated_images`. Le rendu garde coûts, emprises, collisions, lumières, réserves et travaux de leurs contrôleurs historiques. Les coupes sont mesurées sur les composants alpha ; les cadres nominaux ne servent pas à les découper.

Références de style inspectées : `assets/art150/medical-atlas.png` et `assets/art150/district-atlas.png`, originaux documentés de la livraison 1.50. Les indicateurs de charge et de direction sont tracés depuis l'état courant ; aucune lumière ni réserve n'est fournie par une image.
