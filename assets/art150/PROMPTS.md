# Sprites originaux D-17 — 1.50

Quatre atlas natifs Image Gen, vingt supports originaux. Les images sont copiées sans modifier les pixels et leurs sources restent conservées dans `/workspace/generated_images`. Les coupes mesurées isolent chaque silhouette au rendu Canvas. Aucune retouche Python ou dessin d’image de secours ne produit ces atlas.

Chaque support garde son emprise réelle, ses coûts et ses systèmes existants. Les canons suivent le vrai `turretAngle` ; les batteries affichent la réserve réelle. Les étapes de chantier réutilisent les illustrations 1.49 et la fraction de travail payée. Les équipements dessinés dans le pôle de triage ne sont pas une production de médicaments. Les bâtiments historiques, sols, personnages et atlas restent présents.
